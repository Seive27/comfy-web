SETUP

Start in one command

Add Comfy Skill to any project. No config files, no framework lock-in.

STEP 01

Install

Add Comfy Skill to your session with a single npx command. Works with any agent that supports SKILL.md files.

# Install Comfy Skill npx skills add https://github.com/Seive27/comfy-skill.git --skill "comfy-skill-frontend"
STEP 02

Configure

Set your brand constraints and deploy the skill in your agent session. The skill reads automatically on each run.

# Load in your agent prompt I have loaded Comfy Skill v1 as my only source of frontend design rules.
STEP 03

Generate

Define your page kind, audience, and brand vibe. Comfy Skill analyzes the brief and generates a taste profile, skill graph, and rendering strategy.

# Example brief Brief: * Page kind: landing * Product: Comfy Skill * Brand vibe: playful, cozy-tech, retro-futuristic * Avoid: generic AI SaaS patterns, purple gradients
>> You can also install the full bundle with npx skills add Seive27/comfy-skill to load every skill in the repository at once.
