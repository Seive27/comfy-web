Release history

Track every change, feature, and fix in Comfy Skill.

v0.1.0 2026-06-23

Initial public release of Comfy Skill. This release ships with 12 ready-to-use skills covering the full spectrum of frontend development — from taste-driven design systems to brutalist and minimalist UI frameworks. Every skill is a self-contained SKILL.md file that plugs into any AI coding agent supporting the skill format.

  • ADDED comfy-skill-frontend: Core anti-slop skill with brief inference, design system mapping, and pre-flight checks
  • ADDED gpt-comfyskill: Stricter variant for GPT/Codex models with higher layout variance and tighter constraints
  • ADDED redesign-skill: Six-category site audit engine for upgrading existing projects without breaking them
  • ADDED soft-skill: Calm, polished UI direction with spring-based motion and airy whitespace
  • ADDED minimalist-skill: Editorial product UI inspired by Linear with restrained palettes and tight hierarchy
  • ADDED brutalist-skill: Swiss typography, raw mechanical structure, and high-contrast tactical aesthetic
  • ADDED output-skill: Anti-laziness rules blocking placeholder comments, skipped sections, and half-finished output
  • ADDED image-to-code-skill: Reference-frame generation pipeline for pixel-accurate frontend implementation
  • ADDED imagegen-frontend-web: Image-only skill for generating horizontal website section reference frames
  • ADDED emil-design-eng: UI polish and animation philosophy based on Emil Kowalski's design engineering principles
  • ADDED high-end-visual-design: Agency-tier UI architecture with double-bezel components and fluid motion choreography
  • ADDED industrial-brutalist-ui: Tactical telemetry interfaces with CRT terminal aesthetics and mechanical noise
v0.0.2 2026-06-10

Internal preview release. Core architecture and skill pipeline established.

  • ADDED Skill graph routing engine for composing multiple skills into deterministic pipelines
  • ADDED Color Consistency Lock enforcement across all generated output
  • ADDED Shape Consistency Lock with documented mixed-radius exceptions
  • ADDED Page Theme Lock preventing mid-page theme flips
  • CHANGED Refined brief inference engine to support 12 page kinds and 6 audience types
  • CHANGED Expanded ban list from 8 to 22 anti-slop patterns
v0.0.1 2026-05-28

Initial development seed. Foundational concepts and skill format established.

  • ADDED SKILL.md format specification and parser
  • ADDED Three-dial design system (VARIANCE, MOTION, DENSITY) for aesthetic calibration
  • ADDED Em-dash and en-dash ban enforcement
  • ADDED Hero discipline rules: max 2-line headlines, 20-word subtext, no scroll cues
  • ADDED CLI installer for one-command skill setup
  • FIXED Italic descender clipping in display type with forced leading compensation
